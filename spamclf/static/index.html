About this model

A TF-IDF text model with class-balanced logistic regression, trained on 5,171 unique messages from the public UCI SMS Spam Collection. On held-out test messages it reaches a spam F1 score of 0.92 (precision 0.92, recall 0.92).

  • The training data is from the UK and Singapore and is old, so it can be wrong on modern messages such as bank alerts.
  • Short spam is missed more often than long spam.
  • The score is a ranking score, not a calibrated probability. Treat the result as a suggestion, not a decision.

Messages are sent to this server only to be scored; this page does not store them. Developers can use the API documentation.

Demo project for learning. Not for real filtering decisions.
